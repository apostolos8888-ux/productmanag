# Διαχείριση Προϊόντων για Windows

Πρώτη λειτουργική έκδοση μιας τοπικής εφαρμογής καταλόγου προϊόντων, με ελληνικό περιβάλλον.

## Περιλαμβάνει
- Καταχώριση και επεξεργασία ονομασίας, τιμής, κατηγορίας, εικόνας και barcode.
- Αναζήτηση ονομασίας, τιμής, κατηγορίας και barcode.
- Φιλτράρισμα με κλικ σε κατηγορία.
- Κυλιόμενη λίστα με σελιδοποίηση 250 προϊόντων για μεγάλους καταλόγους.
- Χειροκίνητο barcode ή σαρωτή USB που λειτουργεί σαν πληκτρολόγιο (συνήθως στέλνει Enter).
- Εξαγωγή CSV και αντίγραφο ασφαλείας βάσης.
- Τοπική αποθήκευση χωρίς internet.

## Τεχνολογία
- Python 3.10+
- Tkinter για το γραφικό περιβάλλον
- SQLite για τη βάση δεδομένων και ευρετήρια σε τιμή, barcode, κατηγορία και ονομασία.

Η SQLite είναι κατάλληλη για δεκάδες χιλιάδες προϊόντα σε έναν υπολογιστή. Οι φωτογραφίες αντιγράφονται στον τοπικό φάκελο δεδομένων, ενώ στη βάση αποθηκεύεται η διαδρομή τους.

## Εκτέλεση από τον πηγαίο κώδικα
1. Εγκατέστησε Python 3.10 ή νεότερη από το python.org. Κατά την εγκατάσταση επίλεξε **Add Python to PATH**.
2. Κάνε αποσυμπίεση του ZIP σε έναν φάκελο.
3. Κάνε διπλό κλικ στο `run_app.bat`.

## Δημιουργία εκτελέσιμου EXE
1. Εγκατέστησε Python.
2. Άνοιξε τον φάκελο και κάνε διπλό κλικ στο `build_exe.bat`.
3. Το εκτελέσιμο θα δημιουργηθεί στον φάκελο `dist\ΔιαχείρισηΠροϊόντων.exe`.

Η δημιουργία EXE χρειάζεται internet μόνο για την εγκατάσταση του PyInstaller. Η ίδια η εφαρμογή λειτουργεί offline μετά την κατασκευή της.

## Πού αποθηκεύονται τα δεδομένα
`%LOCALAPPDATA%\GreekProductManager\`
- `products.db`: βάση δεδομένων
- `images\`: εικόνες προϊόντων

Μην διαγράψεις αυτόν τον φάκελο αν θέλεις να διατηρήσεις τον κατάλογο. Κράτα αντίγραφα ασφαλείας τακτικά.

## Σημαντικές σημειώσεις πρώτης έκδοσης
- Ο σαρωτής πρέπει να είναι ρυθμισμένος να λειτουργεί ως USB HID keyboard. Συνήθως λειτουργεί χωρίς οδηγό.
- Η αναζήτηση είναι μερική για κείμενο και barcode. Η τιμή μπορεί να αναζητηθεί ως `8,50` ή `8.50`.
- Το CSV εξάγει και τη διαδρομή κάθε εικόνας· δεν ενσωματώνει τις εικόνες στο ίδιο αρχείο.
- Πριν τη χρήση σε πραγματικό κατάστημα, δοκίμασε την εφαρμογή με αντίγραφο των δεδομένων και κράτα backup. Η έκδοση αυτή είναι αρχική και δεν αποτελεί σύστημα αποθήκης/τιμολόγησης με πιστοποίηση.
